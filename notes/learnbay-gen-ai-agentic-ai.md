# Learnbay Gen AI & Agentic AI

## 1. Foundation: Python Basics
The course establishes the core programming competency required for AI development:
* **Syntax & Control Flow**: Mastering `for` loops, `if-else` logic, and function definitions using `def`.
* **Functional Programming**: Utilizing anonymous `lambda` functions.
* **Data & Structures**: Working with the **Pandas** library and understanding **Class** structures (Object-Oriented Programming).

## 2. Machine Learning (ML)
Foundational modeling divided by learning methodology:
* **Supervised ML**: Focused on **Regression** and **Classification**.
* **Unsupervised ML**: Techniques for **Clustering** and **Recommendation** systems.
* **Basic Language Models (NLP)**: Statistical text processing using **NLTK** for preprocessing.
* **Algorithms**: Utilizing **Random Forest (RF)**, **Naive Bayes**, **HMM**, **SVM**, and **KNN**.

## 3. Deep Learning (DL)
Neural networks for complex data like images, video, and contextual text:
* **Core Networks**: **MLP**, **ANN**, and **DNN** used for regression and classification tasks.
* **Computer Vision**: **CNN** architectures for processing **Images** and **Video**.
* **Sequential Data**: **RNN**, **LSTM**, and **GRU** for text processing.
* **Distributed Language Models**: Utilizing **Gensim** for vector space modeling and embeddings like **Word2Vec (W2V)**, **GloVe**, and **FastText**.

## 4. LLM Optimization & Fine-Tuning
Techniques for refining and aligning Large Language Models:
* **Fine-Tuning Methods**: Implementing Parameter-Efficient Fine-Tuning (**PEFT**), **LoRA**, and **QLoRA**.
* **Alignment**: Utilizing **RLHF** (Reinforcement Learning from Human Feedback).

## 5. Generative AI (GenAI) Applications
The implementation phase for diverse content generation:
* **Prompt Engineering**: Essential skills for guiding model behavior.
* **Image & Video (SOTA)**: Using state-of-the-art tools like **DALL-E 2 & 3**, **Imagen** (Google AI), **Stable Diffusion**, and **Flux**.
* **Retrieval-Augmented Generation (RAG)**:
    * **The Technical Pipeline**: Document Loader → Chunking → Embedding → Vector Database → Retriever (Filtering/Relevant Docs) → Augmentation (Enhanced Prompt) → Generation (LLM).
    * **Advanced Frameworks**: Building systems with **LangChain** and **LlamaIndex**.
    * **Specialized RAG**: Exploring Traditional, Graph, Multimodal, and **Agentic RAG**.

## 6. Agentic AI
Transitioning from generation to autonomous reasoning agents:
* **Architectural Patterns**: Implementing **Self**, **Supervisor (PSV)**, **Group**, and **Nested** agent structures.
* **Frameworks**: Mastering **LangGraph** (with LangChain), **AutoGen**, and **CrewAI**.

## 7. Model Context Protocol (MCP)
* **Definition**: A standardized **Set of Rules** designed to manage **LLM Information** and infrastructure.

## 8. Cloud & Full-Stack Deployment
The practical application of all skills in a production environment:
* **Cloud Platforms**: Utilizing **Azure**, **AWS** (Bedrock), and **GCP Vertex AI**.
* **End-to-End Integration**: Developing the complete stack, including **Backend**, **Frontend**, and **Deployment**.
* **Real-time Projects**: Building functional, end-to-end, real-time projects.

## 9. Leaders & Managers
Strategic module focused on oversight, governance, and rapid deployment:
* **Responsible AI**: Ensuring ethical deployment and fairness.
* **Guardrails**: Implementing safety and control mechanisms (Guardrail).
* **No-Code / Low-Code**: Utilizing rapid development tools like **Dify.ai** and **Copilot Studio**.
